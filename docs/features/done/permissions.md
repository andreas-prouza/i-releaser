# Permissions

You can define `users` and `roles`.

Currently these permissions are available:

* `admin`
* `read`
* `start workflow`
* `deploy`
* `run`
* `change check error`
* `4-eyes check`
* `cancel workflow`
* `edit-custom-data`

Permissions can be set on these level:
* `users`
* `roles`
  * `workflows`
    * `stages`
